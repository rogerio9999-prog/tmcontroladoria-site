TM CONTROLADORIA E SOLUÇÕES CONTÁBEIS — SITE
=============================================

ARQUIVOS
  index.html      Página principal (one-page com âncoras)
  parceiros.html  Subpágina de parceiros (AC&FT e Teixeira & Morais)
  styles.css      Folha de estilos compartilhada
  blog.css        Estilos do blog
  posts/          Artigos do blog, um arquivo .md por post
  build.py        Gera o site completo (com o blog) na pasta _site/
  CLAUDE.md       Formato dos posts e guia editorial da rotina diária
  LEIA-ME.txt     Este arquivo

COMO VISUALIZAR
  Com o blog, o site passou a ser gerado. Uma vez só, instale:
      python -m pip install -r requirements.txt
  Depois, para gerar e abrir em http://localhost:8000 :
      python build.py --serve
  A pasta _site/ é o que vai para a hospedagem. Não edite nada dentro dela.

BLOG
  Cada post é um arquivo em posts/ (formato descrito em CLAUDE.md).
  Os posts novos chegam como Pull Request no GitHub. Revise, aprove e
  faça o merge: o site é publicado sozinho em cerca de 1 minuto.
  O campo "checagem" de cada post lista o que precisa ser conferido;
  ele não aparece no site.

RESPONSIVIDADE
  Testado sem rolagem horizontal em 320, 360, 390, 414, 600, 768, 900,
  1024 e 1440 px, nas duas páginas.

  Breakpoints:
    900px  menu vira hambúrguer (inclui Contato e botão de WhatsApp)
    980px  grades de 3 e 4 colunas passam a 2
    760px  layout de coluna única, botões de largura total
    400px  logotipo reduz para "TM." e o botão flutuante vira ícone

PUBLICAÇÃO
  Automática pelo GitHub Pages (.github/workflows/deploy.yml) a cada
  merge na branch main e todo dia às 06:00. Para hospedar em outro lugar,
  rode python build.py e suba o conteúdo de _site/.
